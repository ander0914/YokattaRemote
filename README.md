# 好咖機萬能遙控器 (Yokatta Remote)

專為 **IDEAVISION Yokatta 好咖機** 打造的 Android 藍牙 HID 萬能遙控器（深色夜間模式）。
好咖機免安裝任何 App，手機藍牙配對後即可直接遙控。

## 功能一覽
- 電源 / 休眠、喚醒螢幕、語音搜尋觸發
- 螢幕亮度 ＋ / －、音量 ＋ / －、靜音（支援長按連發）
- 圓形十字方向鍵（上/下/左/右/OK）、返回、首頁、最近使用程式
- 媒體播放（上一首 / 播放暫停 / 下一首）
- YouTube 專屬倒退 10 秒（J）與快進 10 秒（L）

## 免裝軟體：GitHub 雲端自動打包 APK 教學
1. 登入 GitHub（https://github.com），點擊右上角 `+` → `New repository`，建立一個新專案（例如 `YokattaRemote`）。
2. 將本壓縮檔解壓縮後的**所有檔案與資料夾**（包含 `.github` 隱藏資料夾）上傳至該 Repository。
3. 點擊上方分頁 **`Actions`**，即可看到 `Build Yokatta Remote APK` 自動執行（約 2～3 分鐘）。
4. 執行完成出現綠色勾勾後，點進去最下方的 **Artifacts**，下載 `YokattaRemote-APK`。
5. 解壓縮取得 `app-debug.apk`，傳到手機（POCO X8 Pro Max）點擊安裝即可使用。
