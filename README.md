# 好咖機萬能遙控器 (Yokatta Remote) v1.4.0

## v1.4.0 更新內容
- 移除 `YouTube` 啟動按鈕，底部媒體區恢復左右對稱的 `倒退 10 秒` / `快進 10 秒` 大按鍵配置。
- 重構 `OK` 鍵為與方向鍵相同的即時按壓同步機制（`ACTION_DOWN` 按下 / `ACTION_UP` 放開），並在方向盤下方新增「OK 模式切換」膠囊，可免重新編譯直接切換 `Enter 確認`、`DPAD_CENTER`、`空白鍵 Space`、`滑鼠左鍵點擊` 四種標準訊號並自動記憶。
- 若藍牙訊號送出失敗（例如未重新配對導致協定快取舊版），畫面上會即時顯示錯誤提示。
